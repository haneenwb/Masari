## المشكلة

الخريج السعودي في أول سنة بعد التخرج يواجه ثلاثة أسئلة متزامنة: ما الدور الوظيفي الذي يناسبني؟ ما الذي ينقصني للوصول إليه؟ وما أول خطوة هذا الأسبوع؟ الأدوات المتاحة إما اختبارات شخصية عامة لا تنتهي بخطة، أو مواقع توظيف تفترض أن المستخدم يعرف مسبقًا ما يبحث عنه.

## الحل

«مساري» أداة **تقدير ذاتي** تعمل بالكامل داخل متصفح المستخدم. تأخذ إجاباته عن تعليمه وخبرته ومهاراته واهتماماته، ثم تُخرج:

1. **مسارًا وظيفيًا مقترحًا** مع نسبة ملاءمة محسوبة بمعادلة معلنة للمستخدم.
2. **تحليل نقاط القوة والضعف** — كل بند مصحوب بدليله من إجابات المستخدم وزر يفتح الصفحة التي تعالجه.
3. **فجوة المهارات** بنسبة لكل مهارة مقابل متطلبات الدور.
4. **خطة تطوير من أربع مراحل** بمهام قصيرة لكل منها وقت متوقع وأولوية وموعد.
5. **أدوات التجهيز**: سيرة ذاتية مقروءة لأنظمة التتبع (ATS) تُطبع PDF، ومعرض أعمال، وقائمة مراجعة لينكدإن، ورسائل تواصل جاهزة.

### معيار النجاح
بعد عشر دقائق داخل المنصة، يستطيع المستخدم تسمية دوره المستهدف، والمهارات الثلاث الناقصة له، وأول إجراء ينفّذه هذا الأسبوع.

## المبادئ التي بُني عليها المشروع

هذه ليست ميزات، بل قيود التزم بها الكود:

| المبدأ | التطبيق في الكود |
|---|---|
| **لا معلومة غير متحققة** | كل سجل جهة يحمل `status: "placeholder" \| "verified"`. السجل غير المتحقق يُعرض بشارة «بيانات تجريبية» ولا يُعرض له سعر ولا شرط ولا رابط ولا موعد |
| **لا صندوق أسود** | كل نسبة في الواجهة معروضة معادلتها للمستخدم: الملاءمة، الجاهزية، ATS |
| **الخصوصية افتراضية** | لا خادم ولا حساب. التخزين في `localStorage` فقط. ملف السيرة يُقرأ في المتصفح ثم يُهمل ولا يُحفظ. لا تُطلب هوية ولا إقامة ولا جوال ولا عنوان |
| **لا ذكاء اصطناعي مُدّعى** | «مساعد مساري» محرك قواعد داخل المتصفح، مكتوب صراحة تحت كل توصية. لا نموذج لغوي ولا اتصال بالإنترنت |
| **لا أسماء أشخاص** | الجهات والأدوار والمجتمعات المهنية فقط، تفاديًا لمشكلات الدقة والخصوصية |

## المزايا

- **تقييم من ست خطوات** (التعليم، الخبرة، المهارات، الاهتمامات، السيرة، النتيجة) مع حفظ تلقائي واستكمال لاحق
- **قراءة السيرة الذاتية داخل المتصفح** من PDF أو DOCX، مع بديل لصق النص عند تعذّر القراءة
- **أحد عشر مسارًا وظيفيًا** بمجموعات مهارات محددة، قابلة للتوسعة من ملف بيانات واحد
- **لوحة تحكم** فيها المسار والملاءمة وتقدم الخطة وجاهزية الملف ومهام اليوم
- **ثنائية اللغة كاملة** مع انعكاس صحيح للاتجاه: التنقل، الأيقونات الاتجاهية، الرسوم، أشرطة التقدم، الخط الزمني
- **إتاحة**: تنقل بلوحة المفاتيح مع حلقة تركيز ظاهرة، نصوص بديلة للرسوم ذات المعنى، احترام `prefers-reduced-motion`، وسمة داكنة تلقائية
- **تجربة جوال**: القائمة الجانبية تتحول إلى شريط سفلي مع قائمة «المزيد

1. افتح الصفحة الرئيسية واختر مسارًا وظيفيًا، أو اضغط «ابدأ التقييم» مباشرة
2. أكمل الخطوات الست — تظهر نافذة موافقة قبل أول عملية حفظ توضح ما يُحفظ وأين
3. راجع نتيجتك، ثم افتح «القوة والضعف» و«المهارات»
4. اختر مهاراتك المستهدفة واضغط «ابنِ خطتي»
5. جهّز سيرتك من صفحة السيرة الذاتية واطبعها PDF
6. لحذف كل شيء: «المصادر والخصوصية» ← «حذف بياناتي»

### المتصفحات المدعومة
أحدث إصدارات Chrome و Edge و Safari و Firefox على الحاسوب والجوال. يعتمد المشروع على `localStorage` و CSS Custom Properties و `aspect-ratio` و`color-mix`.

## المعادلات باختصار

| المؤشر | المعادلة |
|---|---|
| نسبة الملاءمة | `0.60 × تغطية مهارات الدور + 0.25 × قرب الدور من المجال الأكاديمي + 0.15 × توافقه مع الاهتمامات` |
| جاهزية الملف | `0.45 × جاهزية السيرة + 0.30 × لينكدإن + 0.25 × معرض الأعمال` |
| جاهزية ATS | `عدد بنود المراجعة المجتازة ÷ 6 × 100` |
| مستوى المهارة | `0 / 25 / 50 / 75 / 100` — تُحتسب متوفرة عند 75 فأعلى، وجزئية بين 25 و50 |

الأوزان اجتهادية ومعلنة داخل الواجهة نفسها، وليست معايرة على سوق العمل السعودي. هذا مذكور للمستخدم في التطبيق.

## الحدود المعروفة

مذكورة أيضًا داخل التطبيق في صفحة «المصادر والخصوصية»:

- جميع سجلات الجهات بحالة `placeholder` عدا منصة **عَتَبة**؛ الأسماء كما وردت من صاحبة المشروع، ولم يُتحقق من أي برنامج أو تكلفة أو رابط أو شرط، ولذلك لا تُعرض تفاصيلها
- تصنيف كل جهة مستنتج من اسمها ويحتاج مراجعة، والأسماء الإنجليزية تقريبية
- تصدير السيرة عبر الطباعة إلى PDF بنص قابل للتحديد؛ تصدير DOCX غير مبني
- الخطوط تُحمّل من Google Fonts؛ الاستضافة الذاتية للخطوط لم تُنفّذ
- لا اختبارات آلية في هذه النسخة؛ المراجعة يدوية وفق قائمة الفحص في التوثيق الفني
- لا نسخة React/TypeScript؛ النسخة الحالية ملف واحد للعرض والتحقق من الفكرة

# Masari — English Summary

**Masari** is a bilingual (Arabic-first, RTL) career-development tool for Saudi graduates. It turns a ten-minute self-assessment into one target role, a transparent skill gap, and a four-phase development plan.

### Highlights
- **Runs entirely in the browser.** No accounts, no server, no analytics. State lives in `localStorage`; an uploaded CV is parsed on-device and the file is discarded.
- **No unverified claims.** Every organization record carries a `status` field. Placeholder records are badged as demo data and never show a price, requirement, link or deadline.
- **Every number is explainable.** Match, readiness and ATS scores are computed by documented formulas that the interface shows to the user.
- **Rule-based assistant.** The "Masari assistant" is a deterministic rule engine, labelled as such — not a language model.
- **Full RTL/LTR parity**, keyboard navigation, visible focus rings, descriptive alt text, reduced-motion support and an automatic dark theme.

### Run it
No build step and no dependencies. Clone the repository and open `index.html`, or serve the folder with `python3 -m http.server 8000`. Deploy by enabling GitHub Pages on the `main` branch root.

### Technical documentation
See **[docs/TECHNICAL.md](docs/TECHNICAL.md)** for architecture, state shape, scoring formulas, the data-integrity model and extension guides, and **[docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)** for the source-verification procedure.
